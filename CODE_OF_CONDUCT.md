# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be welcoming, kind and patient.
- Respect different views and experience levels.
- Give and accept constructive feedback gracefully.
- No harassment, insults, personal attacks or publishing others' private information.

## Reporting

Report unacceptable behaviour privately to the maintainer through their GitHub profile, [github.com/krnblds](https://github.com/krnblds). All reports are reviewed promptly and kept confidential.

Maintainers may remove, edit or reject contributions, or ban contributors, for behaviour that breaks this code.
